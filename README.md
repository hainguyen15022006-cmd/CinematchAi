# CineMatch AI

Hệ thống gợi ý phim cho nhóm sử dụng Deep Learning và Group Recommendation.

## Thành viên

- Hải Anh: Data
- Thành: AI Baseline, MF, GMF
- Công Thành: NCF, Hybrid NCF, Text
- Chúc: Backend
- Dương: Frontend
- Hoàng Anh: Testing, Integration, DevOps
- Thành viên còn lại: Group Recommendation và Evaluation

## Dataset

Dự án sử dụng MovieLens 100K. Dataset không được commit lên GitHub và phải được tải bằng script.
